# 08. 难点与解决方案

## 难点 1：数据质量复杂

问题：

```text
链上数据公开，但不等于干净。
PnL、余额、早期买家、资金来源都会被转账、分仓、路由、价格缺失、精度误差、MEV 干扰。
```

解决方法：

```text
第一版不要追求完美 PnL。
先做低成本、鲁棒的风险指标。
```

优先指标：

```text
早期买家 remaining_ratio
前 20 / 50 买家清仓比例
5 分钟 net_buy_usd
trades / unique_traders
buyers / sellers
同 funder 地址数量
新钱包比例
买入前交易次数
```

## 难点 2：同实体识别容易误判

问题：

```text
同 funder、同时间、同 gas pattern 都只能说明疑似关联，不能证明一定是同一个人。
交易所热钱包、聚合器、常见 gas 分发地址可能制造误判。
```

解决方法：

```text
不要做二元判断。
改成证据评分和概率分级。
```

报告表达：

```text
这些早期买家存在较强关联迹象，主要证据是同 funder、买入时间集中、新钱包比例高。
```

避免表达：

```text
这些钱包一定属于同一个人。
```

## 难点 3：meme 市场规则变化快

问题：

```text
今天有效的 sniper、刷量、出货模式，下个月可能失效。
```

解决方法：

```text
建立每日和每周复盘机制。
每次推送都保存当时快照和后续表现。
```

复盘问题：

```text
A 级信号命中率如何？
D 级过滤是否真的过滤掉坏盘？
哪个风险指标最有效？
哪个指标经常误报？
```

## 难点 4：实时性和成本

问题：

```text
Dune 适合研究和回测，不适合高频实时监控。
如果扫描所有 token，查询慢、延迟高、成本不可控。
```

解决方法：

使用双轨制：

```text
Dune：历史分析、样本研究、规则验证
API：实时监听、告警、推送
```

第一阶段先做两道过滤：

```text
基础过滤：
流动性太低、交易太少、holder 太集中，直接丢弃。

行为过滤：
买盘扩散、早期买家、同 funder、清仓比例、刷量迹象。
```

## 难点 5：信号看起来聪明但不可交易

问题：

```text
很多聪明钱信号已经错过窗口。
有些钱包同区块买入、开池几秒买入、依赖机器人速度，普通用户根本无法复制。
```

解决方法：

把 Copyability Score 提前作为核心指标。

判断维度：

```text
开池后 10 秒内买入 → 降低分数
同区块买入 → 降低分数
买入后 1 分钟涨幅过大 → 降低分数
买入时流动性太低 → 降低分数
买入后 5-15 分钟仍有成交量 → 提高分数
买入后仍有净买入 → 提高分数
```

## 难点 6：复盘标准不好定

问题：

```text
一个 token 推送后 15 分钟涨了 80%，1 小时后归零，到底算成功还是失败？
```

解决方法：

提前定义评价口径：

```text
15m 最大涨幅
1h 最大涨幅
6h 最大涨幅
24h 最大涨幅
最大回撤
是否 rug
是否有可执行入场窗口
```

结论不要只看是否涨过，而要看是否有普通用户可以执行的窗口。

## 总体调整建议

项目第一阶段应该从：

```text
AI 帮我找暴涨币
```

调整为：

```text
链上行为风险过滤器：
先过滤骗局和假热度，
再识别少数可复制的高质量信号，
最后由 AI 生成研究解释。
```
