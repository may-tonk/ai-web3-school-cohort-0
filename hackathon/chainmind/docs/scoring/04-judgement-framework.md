# 04. ChainMind 判断框架

ChainMind 不判断“这个 token 会不会涨”，而是判断一个 meme token 的链上机会是否真实、安全、独立、可复制，以及是否值得继续研究。

整体判断分为 8 类。

## 1. 是否进入分析

判断这个 token 是否值得花资源继续分析。

主要依据：

- 流动性是否足够。
- 成交量是否足够。
- 交易人数是否足够。
- 是否属于当前支持范围，例如 BNB meme。
- GoPlus 是否提示高危。
- 是否来自用户指定、重点钱包、watchlist 或 8 小时雷达。

可能结论：

```text
丢弃
进入候选池
进入 Dune 深度分析
```

## 2. 合约安全判断

判断 token 是否存在明显合约风险。

主要数据来源：

- GoPlus。
- BscScan。
- 合约权限。
- LP 状态。
- mint / blacklist / tax / owner 权限。

典型规则：

```text
GoPlus 高危 → 直接 D
LP 风险高 → 降级
权限未放弃 → 提高风险
```

## 3. 买卖盘健康判断

判断买盘是真实扩散，还是假热度。

主要依据：

- 5m / 15m / 1h net_buy_usd。
- buyers 是否增长。
- sellers 是否增长。
- unique_traders 是否增长。
- trades / unique_traders 是否异常。
- buy_volume 和 sell_volume 变化。

风险信号：

```text
trades 高但 unique_traders 低
buyers 多但 sell_volume 更大
net_buy_usd 连续转负
交易量上涨但真实交易人数不涨
```

## 4. 早期买家行为判断

判断早期资金是否已经撤退。

主要依据：

- 前 20 / 50 / 100 早期买家。
- 首次买入时间。
- 买入金额。
- 当前余额。
- remaining_ratio。
- 早期买家清仓比例。
- 大买家是否已卖出或转走。

典型规则：

```text
前 20 早期买家清仓比例 > 60% → 高风险
早期大买家 current_balance 接近 0 → 出货风险
早期买家仍大量持有 → 继续观察
```

## 5. 同实体 / 假共识判断

判断多个钱包买入是真共识，还是同一个实体分仓。

主要依据：

- 同 funder。
- 买入时间集中。
- 新钱包比例。
- gas 来源相似。
- 历史合约交互重叠。
- 多个钱包后续同步卖出。

判断表达不应该绝对化，而应该分级：

```text
大概率独立
存在关联，需要观察
高度疑似同一实体
强关联实体集群
```

这是 ChainMind 的核心差异化之一。

## 6. 钱包质量判断

判断参与的钱包是否真的有 alpha。

主要依据：

- 历史胜率。
- realized PnL。
- trade count。
- median return。
- 最大回撤。
- rug exposure。
- 最近 7D / 30D / 90D 表现。
- 平均持仓时间。
- 买入后 15m / 1h / 6h 表现。

注意：

```text
总 PnL 高 ≠ 有 alpha
历史强 ≠ 当前仍有效
一次赚很多 ≠ 稳定高质量
```

## 7. 可复制性判断

判断普通用户看到信号后是否仍有观察窗口。

主要依据：

- 是否同区块买入。
- 是否开池几秒内买入。
- 买入时流动性是否过低。
- 买入后是否瞬间拉升。
- 是否依赖极高 gas / 机器人速度。
- 买入后 5-15 分钟是否仍有成交量。
- 买入后是否仍有净买入。

核心结论：

```text
高胜率钱包 ≠ 可复制钱包
聪明钱买入 ≠ 普通用户能跟
```

## 8. 是否推送判断

判断是否需要打扰用户。

推荐分级：

```text
A：即时推送
B：进入 8 小时摘要，必要时推送
C：只入库
D：过滤
```

还需要判断：

- 是否重复推送。
- 是否在冷却期。
- 本次扫描已推送多少个。
- 是否从 B 升 A。
- 是否出现重大风险事件。

推送不是把所有候选都发出去，而是只推高价值、可解释、不过载的结果。

## 最终综合判断

最终输出应该包括：

```text
Risk Score
Entity Cluster Score
Wallet Alpha Score
Copyability Score
Opportunity Score
Priority Score
Grade A/B/C/D
```

可观察候选的大致逻辑：

```text
可观察候选 =
    风险不过高
  + 买盘相对健康
  + 早期买家未明显撤退
  + 没有强同实体嫌疑
  + 有高质量钱包参与
  + 这个钱包信号仍有可复制窗口
```

## 总结

ChainMind 的判断目标不是给交易指令，而是回答：

```text
这个链上机会是否真实？
风险来自哪里？
买盘是否健康？
早期资金是否撤退？
钱包信号是否独立？
普通用户是否仍有观察窗口？
是否值得进入人工研究列表？
```
