# 01. 项目定位与边界

## 一句话定位

ChainMind 是一个基于链上行为的 meme 机会与风险过滤系统：

```text
链上数据分析
    + 高胜率地址跟踪
    + 可复制性判断
    + 同实体/刷量/出货识别
    + AI 研究解释
    + Hermes 推送与复盘
```

项目的核心不是预测涨跌，而是帮助用户更早发现风险、更快排除低质量机会，并把少数值得继续研究的候选解释清楚。

## 不做什么

第一阶段明确不做：

- 不做 AI 自动买卖。
- 不做泛化行情看板。
- 不直接让 AI 读取所有原始交易并预测涨跌。
- 不把“聪明钱买入”直接等同于“可以买入”。
- 不输出强交易指令，只输出研究结论、风险提示和观察条件。

## 核心差异化

普通 meme 工具通常展示：

```text
价格
成交量
流动性
holder
top holder
K 线
聪明钱买入提醒
```

ChainMind 要回答更进一步的问题：

```text
哪些地址真的有 alpha？
哪些高胜率地址普通用户能复制？
哪些钱包其实是项目方、机器人、狙击地址或同一实体分仓？
买盘是真实扩散，还是刷量制造的热度？
早期买家是否已经开始出货？
当前 token 是早期机会，还是接盘区？
```

## 第一阶段目标

第一阶段不要急着寻找“必涨 token”，而是做一个可靠的风险过滤器：

```text
先过滤坏机会
再识别可观察机会
最后由 AI 解释为什么
```

优先价值：

- 排除疑似刷量、内盘、出货、同实体分仓 token。
- 识别真正独立且可复制的高质量钱包信号。
- 把复杂链上指标转成可复盘的研究报告。

## 核心原则

```text
程序负责计算
规则负责过滤
AI 负责解释
复盘负责校正
```

AI 的输入应该是结构化摘要，而不是海量原始交易日志。

示例输入：

```json
{
  "token": "XXX",
  "chain": "bnb",
  "signal": {
    "alpha_wallets": 3,
    "copyable_alpha_wallets": 2,
    "copyability_score": 72,
    "market_regime": "risk_on"
  },
  "risk": {
    "top20_holding": "41%",
    "early_buyers_exited": true,
    "same_funder_cluster": true,
    "lp_risk": "medium"
  }
}
```

AI 输出应该回答：

- 是否值得观察。
- 机会来自哪里。
- 风险来自哪里。
- 是否可复制。
- 后续观察条件是什么。
- 不确定性在哪里。
