# BNB Meme 新币真实样本研究报告

日期：2026-05-26

## 1. 报告目的

本报告用于总结 ChainMind Phase 2 中 3 个真实 BNB Chain meme 新币样本的 Dune 数据验证结果。

这不是投资建议，也不是最终风控结论。当前报告的作用是：

1. 验证 ChainMind 是否可以用 Dune API 自动获取真实链上行为数据。
2. 检查 Phase 2 风险评分字段是否能在真实 meme 新币中落地。
3. 观察当前规则是否存在过严、过松或需要补充数据源的问题。

## 2. 当前数据来源

当前报告只使用 Dune 查询结果，不包含第三方安全 API。

已接入的 Dune 查询包括：

| 查询模块 | 作用 |
| --- | --- |
| `trading_activity` | 交易活跃度、交易量、交易人数、DEX 来源 |
| `five_minute_flow` | 5 分钟买卖盘、买卖人数、净买入金额 |
| `early_buyers` | 前 100 个早期买家的买入与剩余持仓情况 |
| `early_buyer_funding` | 早期买家的首个资金来源与同源资金集群 |

当前未接入但后续需要补充的数据：

| 缺失数据 | 重要性 |
| --- | --- |
| Honeypot 检测 | 判断能否卖出 |
| 买卖税 | 判断交易摩擦与潜在恶意税率 |
| 合约权限 | 判断 owner 是否可增发、拉黑、改税 |
| LP 锁定/销毁 | 判断流动性是否可能被抽走 |
| Holder 集中度 | 判断筹码集中与控盘程度 |

## 8. 对项目的启发

这次真实样本验证对 ChainMind 很有帮助：

1. Dune API 路径可以落地，已经能自动生成真实 `TokenSnapshot`。
2. `early_buyer_exit_ratio_high` 在 meme 新币中非常敏感，可能是有效风险信号。
3. `shared_funder_cluster` 能识别早期地址之间的资金关联，是 Phase 2 的核心价值之一。
4. 只靠 Dune 行为数据还不够，必须补充安全 API，否则无法判断 honeypot、税率、LP、合约权限。
5. 当前样本数太少，不能马上把阈值定死，需要更多真实样本校准。

## 9. 当前局限

当前报告有以下限制：

| 限制 | 影响 |
| --- | --- |
| 样本只有 3 个 | 不能代表全部 BNB meme 新币 |
| 缺少安全 API | 无法判断能否卖出、是否高税、是否可被 owner 操控 |
| 缺少 holder 集中度 | 无法判断大户控盘和筹码集中 |
| 缺少价格走势标签 | 无法验证高风险评分是否对应真实后续下跌或归零 |
| 早期买家阈值未校准 | 可能对 meme 新币过严 |

## 10. 下一步建议

下一步不建议急着接 AI 生成报告，而应该先补真实样本和关键安全数据。

建议顺序：

1. 再收集 5-10 个 BNB meme 新币地址。
2. 至少加入 2-3 个相对健康或存活时间更长的 meme token 作为对照组。
3. 接入安全 API，补齐 honeypot、税率、LP、合约权限。
4. 再检查 `early_buyer_exit_ratio_high` 和 `shared_funder_cluster` 阈值是否需要调高。
5. 阈值稳定后，再让 AI 基于 `risk_evidence` 生成自然语言研究报告。

## 11. 报告结论

ChainMind Phase 2 当前方向是正确的。

我们已经不是只在做模拟测试，而是已经完成了真实 BNB meme 新币的 Dune API 数据获取、结构化映射、风险评分和研究归因。

当前最重要的结论是：

- 系统可以落地；
- 风险证据可以从真实链上数据中提取；
- 现阶段最需要的是扩大真实样本和补充安全 API；
- 不应该马上把当前 3 个样本的阈值当成最终生产规则。
